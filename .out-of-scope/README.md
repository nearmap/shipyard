# Out of scope

Ideas Shipyard has considered and deliberately declined, one file per concept. Each records the decision, why, and every request that raised it, so the next proposal starts from the reasoning instead of re-deriving it.

Before proposing a change to Shipyard, check here. A match is not a veto: if the reason no longer holds, say why and update or delete the file in the same PR. A deferral ("not now") does not belong here; only a decision with a durable reason does.
